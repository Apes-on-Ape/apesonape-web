## How to Extract Frames

You can use any image editing software (like GIMP, Photoshop, or online tools) to:
1. Open the sprite sheet image
2. Crop each frame to the correct size
3. Save as individual PNG files with the naming convention above

The frame sizes should be:
- IceVFX1: 40x32 pixels
- IceVFX2: 64x64 pixels  
- DarkVFX1: 40x32 pixels
- Firebolt: 32x32 pixels
